# HuddlersFire · 허들러즈 불멍

인디게임개발자 Discord 커뮤니티 사람들이 함께 쉬고 놀기 위한 웹 기반 2D 쿼터뷰 캠프장입니다. 최대 16명이 공개방 목록·초대 링크·코드로 입장하며, 게임 상태는 방장을 중심으로 WebRTC DataChannel로 동기화합니다. 사용자 결정의 근거와 변경·충돌 절차는 [의도 기준](docs/project-intent.md), 원하는 경험과 미정 범위는 [제품 방향](docs/product-direction.md)에 정리합니다.

**현재 공개 버전 29: INT-18 새 필드·규약 v19.** 세 맵의 배치·동선·카메라·필드 HUD와 52개 자산/67프레임을 전면 재생성했습니다. 16석의 방향·접촉과 모바일 영상/조작을 맞추고 기존 공유 기능을 유지합니다. 201개 회귀·PC/모바일·16인 RTC/승계와 공개 파일 72개/API를 확인했습니다. [제작과 재현](docs/sprite-authoring.md) · [검증 기록](docs/validation.md). 기존 참가자는 새로고침 후 다시 입장합니다. 아래 이전 버전 설명은 이력입니다.

배포 사이트: [허들러즈 불멍](https://huddlers-fire-camp.gywkd77.chatgpt.site). 2026-11-05 공개 사이트 버전 23(통신 규약 v16)에 부스 대표 이미지를 공식 YouTube 트레일러 썸네일로 교체했습니다. 부스 공통 템플릿·트레일러 중심 소개·SNS 활성/미등록, 기존 맵 확장·포탈·라디오·통나무·공동 성장과 휠 조작을 유지합니다. 새로고침하면 최신 화면을 사용할 수 있습니다. 공개 응답과 배포 파일의 일치 여부는 [검증 기록](docs/validation.md)에 남겼습니다.

## 구현 범위

- 게임 전시 부스 공통 템플릿, 공식 YouTube 썸네일 대표 이미지, 트레일러 중심 소개와 SNS 활성/미등록 표시(공개 버전 23). [작성 방법](docs/game-exhibits.md).
- 각 맵 가로·세로 약 2배, 불멍↔놀이터·게임 전시장 포탈, 가까이에서 E/화면 버튼으로 이동·부스 상호작용, PARRUITS! 소개·공식 이미지·관련 링크 팝업(공개 버전 21·규약 v16)
- WASD / 방향키 이동, 화면 기준 방향, 모닥불·나무·텐트 충돌
- E 키로 앉기·일어서기, 통나무 좌석·불 중심 자동 확대·불 위 대화, 인당 10분 장작·공동 모닥불 레벨·공유 외형 5종과 잔불·녹음 기반 소리
- Shift 달리기·Space 점프·C 웅크리기, Q/숫자키 감정표현 6종, 키보드·터치 동작 버튼
- Enter 방 채팅·오래된 메시지부터 아래로 쌓이는 목록·겹침을 줄인 말풍선, 한글 입력, 최근 100개 방 내 기록
- 가장자리 낙사·안전 복귀, 트램펄린, F 연쇄 들기·공중 잡기·던지기와 Space 탈출
- 총·눈뭉치·폭탄 장난감과 체력 소모 없는 밀림
- 라디오 탭 또는 R키로 어디서든 함께 듣는 밤, 공용 YouTube 신청·대기열, 방장 재생 관리, 개인별 라디오 음소거·음량과 효과음 전체 음량
- 닉네임·캐릭터 색상, 혼자 둘러보기
- 공개방 목록과 공개/초대방 생성, 6자리 방 코드와 초대 링크, 최대 16명, 참가·퇴장·재접속
- 작업 메모·수동 상태·개인 작업 시간, 호출과 날짜·시간 기록. 작업 중·자리 비움에도 상호작용
- 대화·사람·내 상태·놀이·라디오 패널과 작은 화면 하단 메뉴, 간결한 상태 배지와 상세 메모
- 걸어서 밀고 달려서 차는 공유 축구공, 지원 환경의 YouTube 작은 창
- 필드 보기·확대/축소·내 캐릭터 추적, 지원 브라우저에서 크기를 조절하는 PIP 창
- 방장이 이동을 검증하고 상태를 전파하는 P2P 구조
- Discord OAuth2 `identify` 권한으로 계정 연결 후 입장 및 프로필 사진 연결 (자격증명 설정 필요)

## 실행

Node.js 24 LTS 권장. 설치·빌드·새 로컬 DB의 전체 마이그레이션·서버 실행 순서는 [web 실행 안내](web/README.md#local-development)를 따릅니다. 적용된 SQL은 다시 실행하지 않습니다. Windows PowerShell에서는 `npm.cmd`를 사용합니다.

## 검증

```powershell
cd web
npm.cmd test
npm.cmd run typecheck
npm.cmd run test:render
# Worker(5191)와 test:qa-server(5192)를 실행하고 CAMP_TEST_URL을 5192로 지정한 뒤:
npm.cmd run test:network
```

- `test`: SQLite에서 실제 로비 API를 실행해 동시 입장 정원, 권한, 방 종료, 인증, 이동을 검사합니다.
- `test:network`: 별도의 세션 16개와 실제 루프백 ICE/DTLS/SCTP 연결을 사용합니다. Node의 WebRTC 구현을 사용하므로 브라우저 호환성·서로 다른 인터넷 환경의 NAT 통과 검사를 대신하지 않습니다.
- `test:render`: 게임의 Canvas 코드를 직접 실행해 `web/outputs/camp-desktop.png`, `camp-mobile.png`를 생성합니다. 전체 웹 UI의 브라우저 캡처는 아닙니다.
- 확장 렌더 장면은 `web/outputs/camp-actions.png`, `camp-actions-mobile.png`, `camp-actions-reduced.png`입니다.

## 새 동작과 함께 듣기

WASD/방향키 이동, Shift+이동으로 달리기, Space 점프·들린 상태에서 내려오기, E 앉기·일어나기, C를 누르는 동안 웅크리기, Q 감정표현 열기와 1~6 선택, F 가장 가까운 친구 들기·마지막 이동 방향으로 던지기, Enter 채팅, Esc 채팅에서 캠프장으로 복귀합니다. 모바일은 이동 버튼과 달리기 전환·점프·앉기 버튼을 제공합니다. 캐릭터나 이름표, 참가자 목록을 누르면 사진·닉네임·방장 여부·현재 동작·연결 상태·들어올리기 허용 정보를 볼 수 있습니다. 라디오 근처에서 R키나 버튼을 누르면 함께 듣는 밤 팝업이 열립니다. 친구에게 들리는 것을 원하지 않으면 설정에서 들어올리기 허용을 해제합니다. 떨어지면 약 2초 후 모닥불 근처로 돌아옵니다.

신청곡은 라디오 팝업에서 YouTube 영상 링크로 등록합니다. 전원 신청할 수 있으며 대기열은 전체 30곡·인당 3곡입니다. 방장이 전체 재생·일시정지·다음 곡·대기곡 삭제를 관리합니다. 팝업을 닫아도 작은 공식 YouTube 플레이어에서 재생이 계속되며, 라디오 말풍선에 곡 제목·신청자·재생 상태가 표시됩니다. 검색·음성 채팅은 포함하지 않습니다.

상단 설정 버튼에서 모닥불·음악 음량, 내 음악 듣기, 들어올리기 허용, Discord 프로필 연결을 관리합니다. 개인 설정은 같은 브라우저에서 유지됩니다. Discord 인증은 별도 창에서 진행하므로 캠프장이 유지됩니다. 새 개발자 앱 등록은 [Discord 설정 안내](docs/discord-setup.md)를 따릅니다.

공식 YouTube 플레이어를 화면에 표시하며, 플레이어가 있는 문서의 가시성을 기준으로 재생합니다. 지원 환경에서는 YouTube 작은 창으로 옮겨 원래 탭이 가려져도 함께 들을 수 있습니다. 자동재생이 차단되면 재생 허용 버튼을 누릅니다. 광고·버퍼링·지역/연령/외부 재생 제한 때문에 완전히 같은 시점의 재생을 보장하지 않습니다. 오류는 각자 표시하고 방장이 필요하면 다음 곡으로 넘깁니다. 신청곡·채팅과 복구 상태는 참가자 메모리에서 공유하며 전원 종료 시 사라집니다. 이전 버전 참가자는 모두 새로고침해야 합니다.
