### 이번 한 컷의 제작 규격

- 논리 캔버스: **64×96픽셀**, 세로형. 몸 전체와 손발이 잘리지 않도록 여백을 둬.
- 시점: 고정 2:1 쿼터뷰. 캐릭터가 화면 왼쪽 위(NW)를 바라보는 뒷사선 모습. 정면·옆면·다른 방향으로 바꾸거나 좌우 반전으로 대체하지 마.
- 자세: 양발로 자연스럽게 서 있는 idle. 팔은 편하게 내리고, 머리카락·옷·모자·액세서리·표정은 없는 레이어 조립용 단순 기본 신체야. 배경·의자·소품은 그리지 마.
- 좌표는 캔버스 왼쪽 위가 (0,0)이야. 양발 지면 기준점은 **(32,88)**, 머리 중심은 **(32,28)**을 목표로 해 줘. 이는 첫 컷을 위한 초안이므로 비율이 부자연스러워지면 몸을 늘이지 말고 조정 제안을 별도로 알려 줘. 착석 좌면은 이번 컷에 적용하지 마.
- 1 논리 픽셀 격자에 맞춘 의도적인 계단형 외곽, 연결된 색면, 일관된 짙은 갈색 윤곽선과 명암 단계를 사용해 줘. 외곽의 잔점·구멍·삐져나온 색, 거친 잡티, 디더링, 블러, 매끈한 그라데이션은 피하고 손발과 머리 윤곽을 실제 크기에서 또렷하게 해 줘.
- 팔레트는 원본의 따뜻한 피부색과 읽기 좋은 밝음/중간/그림자를 유지해 줘. 억지로 6색에 맞추지 말고 필요한 색을 의도적으로 골라 줘. 게임 조명은 나중에 적용하므로 강한 불빛·검은 야간 음영을 그림 자체에 굽지 마.
- 실제 투명 배경 PNG. 논리 픽셀의 alpha는 0 또는 255로 하고, 반투명 테두리·광선·바닥 그림자·체커보드 그림·배경색·글자·격자선은 넣지 마.
