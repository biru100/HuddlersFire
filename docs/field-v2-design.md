# 게임 필드 재구성 · INT-18

2026-11-05 사용자가 기획 의도만 남기고 내부 배치·이미지를 전면 재생성하는 계획의 구현을 승인했다. 범위는 세 맵의 배치·캐릭터/시설/지형/효과·카메라·필드 HUD와 제작/검증 경로다. 배포·커밋·푸시는 포함하지 않는다. 이전 그림·좌표·체형·63프레임 수·섬 윤곽은 새 설계의 기준이 아니다.

## 경험과 공간

- **불멍:** 16석의 공동 불을 중심으로 네 면의 통나무 두 개씩 배치한다. 통나무의 접선은 바닥 투영의 두 축과 일치시키고, 몸은 각 면에서 불을 향한다. 좌석 사이·앞뒤 진입 통로와 바깥 보행 고리를 둔다. 라디오는 좌석을 가리지 않는 옆 쉼터에, 포탈은 보행 고리와 이어지는 좌우의 길 끝에 둔다.
- **놀이터:** 중앙의 공놀이 공간, 떨어진 트램펄린과 착지 공간, 주변의 그늘과 장난감 보관 시설로 구성한다. 포탈 진입은 중앙 놀이 공간과 분리한다. 경계와 장식은 실제 이동을 설명하며 끊어진 울타리를 임의로 흩뿌리지 않는다.
- **전시장:** 화면에서 두 전시 스크린이 같은 관람선에 보이도록 배치하고 각 부스 앞에 정지/소개 공간을 둔다. 입구에서 갈라지는 관람 길과 귀환 길을 시설 좌표에서 유도한다. 시장 매대 대신 게임 전시 스탠드를 사용한다. 공식 썸네일·트레일러·링크는 유지한다.

확장된 공간과 세 맵 분리, 공동 라디오/상태/채팅, P2P/승계, 장난감과 들기 규칙, 공동 불 성장과 장작 간격은 유지한다. 충돌·스폰·좌석·도보 동선은 새 배치를 따른다. 규약은 배치가 다른 구버전과 섞이지 않도록 올린다.

## 새 시각 명세

새 기준 원화는 `art/sprites/field-v2/bootstrap.json`의 제품 의도만으로 생성한다. 기존/파일럿 그림을 긍정적 이미지 참조로 사용하지 않는다. 깨끗한 동화책 형태와 절제된 질감, 짙은 청록·황토·크림의 캐릭터, 자연스러운 녹색과 밝은 흙길, 읽기 쉬운 전시 스크린을 같은 시점과 명암으로 맞춘다. 컬러와 다크·색 이외의 번호/포탈 표식은 이어간다.

전체 목록은 모든 사용자 동작과 필요한 착석 방향, 실제 사용하는 시설·지형·효과를 포함한다. 대표 부분은 전체 명세의 일부만 생성해 검토하고 전체 출력은 새 자산만으로 구성한다. 정식 출력에서 이전 manifest의 자동 보완을 금지한다. 기존 원본은 이력으로 보존한다.

## 필드와 UI

기본 시야에서 사람·불·이동 목적지가 먼저 보이도록 카메라와 HUD를 함께 정한다. 카메라/상태 조작은 작은 상단 도구로, 불 조작은 필요한 상황의 작은 하단 도구로 정돈한다. 빈 라디오는 대기 표시로 줄이고 재생 중 YouTube 영상은 유지한다. 모바일의 열린 대화 패널과 필드 복귀 동작도 확인한다. 로비·설정·소개 패널 전체를 새 제품 흐름으로 바꾸지 않는다.

## 완료 판단

원형 단계는 공간 관계·접촉·대표 그림체를 검증하며 전체 제작 성공으로 보고하지 않는다. 전체 단계는 선언된 자산/동작/방향/테마의 누락과 이전 이미지 참조가 없어야 한다. 검토 해시에는 배치·스폰·좌석·필드 UI도 포함한다. 실제 Canvas와 격리 UI, 16인 RTC/승계, 성능을 구분해서 확인한다. 실패 장면은 수정 후 재검토한다.
