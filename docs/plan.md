# 초기 제품 계획과 과거 승인 기록

> 이 문서는 초기 설계와 당시 승인 내용을 보존한 기록이다. 이후 변경을 모두 반영하지 않으므로 현재 구현 지침으로 사용하지 않는다. 방장 퇴장 시 종료, Shift 웅크리기, 중첩 들기 금지·던지기 제외 등은 이후 변경됐다. 현재 제품 기준은 [제품 방향](product-direction.md), 실제 모듈·승계 규칙은 [구조 문서](architecture.md), 동작·검증 결과는 [README](../README.md)와 [검증 기록](validation.md)을 확인한다.

## 확정된 방향

- 허들러즈 커뮤니티에서 함께 불멍하는 웹 게임.
- 외부 웹사이트에서 실행하는 2D 쿼터뷰. 최대 16명.
- WASD 상하좌우 이동. 실제 조작 방향은 화면 기준.
- 웹 실행과 P2P를 EOS보다 우선. 브라우저 지원 제약 때문에 1차 버전은 자체 코드 로비 + WebRTC.
- Discord는 현재 프로필 사진을 가져오는 용도로만 사용. OAuth2 identify 권한만 요청.
- 게스트 참여를 제공하며, Discord 음성 기능은 기존 통화를 사용.

## 시스템

1. HTTPS 서버는 세션 쿠키·로비 멤버·SDP/ICE 교환을 담당한다. 구현은 Vinext/Cloudflare Worker와 D1.
2. 참가자는 방장에게 WebRTC 연결을 만든다. 16명일 때 방장에는 15개 연결이 생긴다.
3. 참가자는 위치 대신 이동 방향과 앉기 상태를 전송한다. 방장은 속도·장애물을 검증하고 게임 상태를 약 15Hz로 전파한다.
4. 참가자 화면은 이동 예측과 위치 보간을 사용한다. 게임 위치는 D1에 저장하거나 HTTP로 중계하지 않는다.
5. 방·연결 협상·인증만 서버에 남긴다. 순수 정적 파일 호스팅만으로는 멀티플레이를 운영할 수 없다.

## 파일

- `web/app/camp.tsx`: 프로필, 방 생성/참가, 참가자 목록, 소리·조작 UI
- `web/lib/camp-renderer.mjs`: 캠프장·캐릭터 Canvas 렌더링, Web Audio 합성
- `web/lib/camp-world.mjs`: 좌표계, 이동, 충돌, 16명 시작 위치
- `web/lib/camp-network.mjs`: WebRTC, 협상, 재접속, 방장 시뮬레이션
- `web/lib/camp-api.mjs`: 세션, 코드 로비, 시그널링, Discord OAuth, TURN 자격증명
- `web/db/schema.ts`, `web/drizzle/`: D1 스키마와 마이그레이션
- `web/tests/`: API·이동, 통신, 렌더링 검증

## 1차 동작과 한계

- 방장이 떠나면 방을 종료. 비정상 이탈은 90초 뒤 정리하며 다른 요청 시 만료를 확인한다.
- 재접속은 같은 방의 참가 자격이 유지되는 동안 최대 3번 자동 시도. 새로고침 시 기존 방을 떠나며 코드로 다시 입장한다.
- Discord 자격증명이 없으면 연결 버튼에 준비 중 상태를 표시하고 게스트 기능은 유지한다.
- TURN 설정이 없으면 직접 연결 가능한 네트워크에서만 통신할 수 있다. 운영 전 TURN 설정과 서로 다른 실제 네트워크 테스트가 필요하다.
- 코드 소지자 참가 방식이다. Discord 서버 소속 확인이나 비밀번호 방은 구현하지 않았다.
- 최종 접속 대상을 공개할 때는 호스팅 서비스의 접근 설정을 별도로 결정한다. 현재 Sites 신규 생성 기본값은 소유자 전용이다.

## 검증 기준

- 동시 참가 요청이 16명 정원을 넘지 않아야 한다.
- 다른 세션은 참가자 ID만 알아도 게임에 접근하거나 퇴장시킬 수 없어야 한다.
- 게임 상태가 실제 WebRTC 채널로 전달되어야 한다.
- 방장 종료, 연결 재시도, 잘못된 코드, 인증 취소·만료를 처리해야 한다.
- 전역 설정을 변경하거나 computer-use로 사용자 UI를 조작하지 않고 검증 가능한 범위까지 확인한다.

## 승인된 기능 확장 (2026-11-03)

- Shift 유지형 웅크리기·티배깅, 기존 E 앉기 유지.
- Q 선택창과 1~6 단축키의 인사·웃음·하트·박수·춤·놀람. 이동/자세 변경으로 취소하고 3초 후 종료.
- Enter 방 채팅, 200자·초당 1개·최근 100개, 5초 말풍선. 한글 조합과 입력 포커스를 처리.
- 보이는 지면 가장자리 밖으로 나가면 낙사하고 약 2초 후 안전한 시작점으로 복귀. 불이익 없음.
- F 가장 가까운 허용 대상 한 명 들기/내려놓기, Space 직접 탈출, 들리기 허용 해제, 중첩 들기 금지와 이탈 시 안전 해제. 던지기는 제외.
- 트램펄린에 착지하면 자동 재도약. 들고 있을 때 함께 상승하고 가장자리를 넘으면 관계 해제 후 각각 추락/복귀.
- 전원 YouTube 링크 신청, 방장 재생·일시정지·건너뛰기·대기열 관리. 전체 대기 30곡·인당 3곡, 중복 영상 방지, 개인 듣기/음량.
- 공식 플레이어 표시, 자동재생 차단과 숨김/비활성 탭 처리, 단조 시계·RTT 보정·진행 위치 공유. 실제 재생 시점의 완전한 일치는 보장하지 않음.

추가 소스는 `web/lib/camp-protocol.mjs`, `camp-media.mjs`, `web/components/camp/{action-bar,chat-panel,music-panel}.tsx`, `web/tests/features.test.mjs`이다. 기존 world/network/renderer, 메인 화면, 스타일과 통신/렌더 검사를 확장했다. 게임 상태·채팅·신청곡은 방장 메모리에서 관리하고 D1 스키마는 유지한다.
