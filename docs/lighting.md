# 필드 조명·그림자·노멀맵

INT-22 로컬 앱의 UI 다크 선택은 필드 조명/색상과 분리한다. 앱은 항상 컬러 필드와 기존 밤 조명을 렌더링하고 이름표/패널은 개인 테마를 따른다. 아래 다크 자산의 직접 렌더 검사는 과거 묶음과 제작 경로의 호환 검사이며 현재 제품이 필드를 흑백으로 표시한다는 뜻이 아니다. PNG·노멀·광원 계산은 이번에 변경하지 않는다. 후속 배포로 공개 버전 38에 반영됐으며 [검증 기록](validation.md)을 따른다.

현재 공개본은 **버전 33·`field-night-v1` 불멍 야간 조명**이다. 사용자 계획 승인에 따라 불멍 맵의 기본 표현을 밤으로 구성하고, 후속 배포 요청으로 공개했다. 아래 버전 32의 `field-shadow-v4`와 최초 조명 배포 설명은 이전 이력이다.

INT-19의 구현으로, 사용자 후속 배포 요청에 따라 스프라이트 윤곽 그림자 수정본을 **공개 버전 32**에 반영했다. 현재 구아슈 원화·배치·놀이·컬러/다크 선택을 유지하며 접지와 빛의 반응을 보완한다. 물리·공유 좌표·규약 v19·DB 스키마는 바꾸지 않는다. 배포 근거는 [검증 기록](validation.md)을 따른다.

최초 공개 버전 31 이후 사용자 지적으로 그림자 품질을 재검토하고 `field-shadow-v4` 수정본을 연결했다. 로컬 검증 후 사용자의 명시적인 배포 요청으로 공개 버전 32에 반영했다. 이전 타원 방식의 자연스러움 통과 판단과 v3의 지나치게 약한 명암 판단은 정정했다.

## 표시 경로

`CampRenderer`가 카메라·깊이·동작·클릭 영역을 계산한다. `camp-scene-frame.mjs`의 공통 투영과 정렬을 사용하고, `camp-draw-context.mjs`가 기존 Canvas 호출을 장면 명령으로 기록한다. 동일한 상하체 혼합·착석 접촉·사진 앞 손 순서가 두 경로에 적용된다. 기록된 변환은 native Canvas 좌표와 검사로 대조한다.

- WebGL2: PixiJS 8.14.3의 필드 레이어, 자체 노멀 조명 셰이더. 원화·노멀은 한 번 올리고 재사용한다. 이름표·말풍선·조작 UI는 조명과 분리한다.
- Canvas: WebGL 미지원·초기화/자원 실패·컨텍스트 손실 시 기존 입력 Canvas에 그린다. 개선된 접촉·투영 그림자와 캐시한 빛 번짐을 제공하며 노멀맵 표면 조명은 제공하지 않는다.
- 입력 Canvas는 `data-camp-input`, GPU Canvas는 `data-camp-world`로 구분한다. 테마·패널·PIP에서 입력 포커스·클릭 좌표·채팅 초안을 보존한다.
- 사진은 기존 Discord URL을 공유 상태에 유지하고, 고정 CDN 전용 `/api/camp/avatar/<id>/<hash>.png`로 공급한다. 이 읽기는 DB 가용성과 독립적이며 이미지 형식·크기·리다이렉트를 제한하고 제한된 캐시를 쓴다. Workers에서는 `redirect: 'manual'`로 요청하고 비정상·리다이렉트 응답을 거절한다. `redirect: 'error'`는 런타임에서 지원되지 않는다. 사진과 전시 이미지는 노멀 조명을 받지 않는다.

## 재질 제작

`art/sprites/material-spec.json`이 형태·강도·접촉 폭·그림자 높이의 명세다. `tools/lib/material-assets.mjs`는 검토된 필드 v2 원본 및 동결된 색상 manifest를 참조해 수치 채널을 만든다. 새 색 원화를 생성하거나 원화의 명암을 정답 높이로 해석하지 않는다.

노멀은 view X=오른쪽, Y=위쪽, Z=관찰자 방향이며 RGB에 정규화한 벡터를 저장한다. alpha는 표면 조명 마스크다. 원형 사진 영역과 투명 영역은 조명 마스크에서 제외한다. 색상·노멀의 프레임·UV·자르기·반전이 일치해야 하며 색상용 팔레트 보정은 노멀에 적용하지 않는다. 여섯 색과 다크 변형은 같은 노멀을 공유한다.

시설은 실루엣의 완만한 두께와 작성한 면 방향, 캐릭터는 큰 몸 형태와 실루엣을 사용한다. 바닥은 이음새 없는 약한 요철이다. 이는 단일 그림에서 정확한 3D 구조를 복원한 결과가 아니다. 목재·옷은 과한 광택 없이 원화의 명암을 기준으로 완만하게 증감한다.

## 광원과 차폐

INT-20은 확대된 나무·텐트의 실제 표시 범위에 맞춰 가림과 그림자 마스크 크기를 함께 늘린다. 기본 머리에는 읽을 수 있는 최소 주변광을 재질별 `ambientLift`로 더한다. 값은 기본 0이며 절차적 기본 얼굴에만 지정한다. 얼굴은 기존 주변광·직접광·노멀 반응도 유지하고 사진·발광 요소의 예외는 바꾸지 않는다. 다크 머리의 보정값은 무채색이다.

불멍의 조명은 `원화색 × (약한 밤 주변광 + 모닥불 직접광 + 랜턴 직접광)`을 사용한다. `sceneLighting`은 UI 테마와 구분한 맵별 표현이며 불멍에서만 활성화한다. 컬러는 차가운 주변광과 따뜻한 불빛, 다크는 무채색 광량을 사용한다. 놀이터·전시장의 기존 표현은 유지한다. 세계 좌표의 거리·높이로 감쇠를 계산하고 카메라·DPR·확대가 동일 지점의 광량을 바꾸지 않게 한다.

기본 노출과 노멀 강도를 분리한다. 노멀 draw를 끄거나 채널이 없는 자산에도 밤 주변광과 직접광을 적용한다. `unlit` 목록은 기존 노멀 제작 제외 목록이며, 밤 노출의 일괄 예외가 아니다. 몸·기본 얼굴·시설·지형·무기·공은 수광 대상, 불꽃·불티·충돌 빛은 발광 요소, 사진·공식 미디어·이름표·감정 아이콘은 식별성을 보존할 요소로 구분한다. 기본 얼굴은 캐시한 둥근 수치 노멀을 사용하고 몸 번호 표식도 주변광과 직접광을 받는다. 외부 사진을 재질 계산이나 그림자 마스크로 읽지 않는다.

모닥불의 색·광량은 기존 불 외형·연료·장작 반응과 캠프 시각을 사용한다. 다크 모드는 무채색 광량을 사용한다. 모션 감소에서는 깜빡임을 멈추되 연료 변화는 표시한다. 주변 랜턴을 포함해 최대 세 개의 영향 광원만 사용하며 화면 밖 광원은 제외한다. 조명 때문에 네트워크 메시지를 추가하지 않는다.

접촉 그림자와 투영 그림자는 분리한다. 색 원화의 alpha와 실제 몸 합성에서 윤곽 마스크를 캐시한다. 시설의 크기·방향·표시 오프셋과 캐릭터의 착석 보정은 `camp-scene-contract.mjs`의 같은 기하를 사용한다. 벤치는 축에 맞는 바닥 접촉선에서 다리의 접촉 구간을 찾으며, 투영에도 다리 사이 빈 영역과 원화 윤곽을 보존한다. 캐릭터 마스크에 사용자 사진을 넣거나 매 프레임 원화를 다시 읽지 않는다.

그림자는 공통 세계 광원의 반대쪽 바닥으로 짧게 투영한다. 모닥불·랜턴 모두 같은 경로를 사용하고 임의 고정 우하향 투영은 제거했다. 정적·동적 그림자는 모두 사물 이전의 지면 패스에서 그리며 섬의 둥근 등각 경계를 벗어나지 않는다. 광원 선택·품질 단계는 번짐·그림자·노멀 이전에 한 번 적용한다. 높이 픽셀 단위는 캐릭터와 동일한 40px다. 좌/우 진단도 세계 광원을 변경하여 세 경로에 함께 전달한다.

투영은 alpha와 접촉선을 이용한 2.5D 근사이며 정확한 3D 높이 복원이 아니다. 부드러운 면광원 분위기를 위해 길이 상한과 높이 감쇠를 적용한다. 낮은 벤치 위로 지나는 빛과 높은 나무에 가려지는 빛은 별도 높이 차폐 계산으로 구분한다. 높은 들기 연쇄·광원과 동일한 위치에서도 유한한 결과를 낸다.

그림자 가독성은 진단광보다 일반 모닥불 광량·기본 카메라에서 먼저 확인한다. v3은 거리의 제곱 감쇠와 낮은 농도를 겹쳐 중간 거리 투영이 약 4%로 내려갔다. v4는 투영의 거리 감쇠를 선형으로 바꾸고 발/다리 접촉 농도를 높인다. 형상이 올바르거나 강한 진단광에서만 보이는 것은 기본 장면의 명암 검토 통과를 대신하지 않는다.

## 성능과 수명

Canvas 야간 폴백은 같은 세계 광원 입력과 거리/높이 기준을 사용하되 노멀 방향 명암과 지면 합성은 단순화한다. 지면은 캐시한 밤 주변광과 빛 번짐, 사물은 잘라낸 프레임의 색 보정 캐시를 사용한다. 색 보정은 1/24 간격으로 양자화하고 최대 192개·16MB를 보존하며 renderer 종료 시 해제한다. 매 프레임 전체 장면을 읽거나 복사하지 않는다. `data-camp-lighting`은 실제 맵의 표현을 나타내고, 밤 필드 위 상태·시간·이동 안내의 글자 대비만 보완한다.

빛 번짐은 작은 사전 렌더 텍스처, 정적 그림자·바닥 노멀은 절반 해상도 버퍼를 사용한다. 정적 접촉과 광원별 투영을 따로 캐시해 밝기 깜빡임·미세한 연료 변화로 다시 만들지 않는다. 캐릭터 그림자 마스크는 절반 해상도로 만들되 원래 표시 좌표로 투영한다. 마스크는 최대 256개를 보존하고 부드럽게 하는 처리는 최초 생성에만 적용한다. 현재 테마에 이미 로딩한 원화를 사용하며 다크 진입 때문에 컬러 원화를 추가 요청하지 않는다. 조명을 받지 않는 그림은 Sprite 배치로 묶고, 프레임 공통 광원 uniform과 사물별 차폐 결과를 공유한다. 화면 전체를 매 프레임 Canvas에서 WebGL로 복사하거나 동적 blur를 적용하지 않는다.

GPU 텍스처는 사용 시각에 따라 정리하며 80MB를 넘으면 오래된 항목을 먼저 해제한다. 수치는 텍스처 추정치이며 프레임버퍼·드라이버 메모리 전체를 뜻하지 않는다. 장기 지연을 감지하면 보조 광원을 줄이고 회복에는 긴 관찰 시간을 적용한다. 입력·물리 주기는 바꾸지 않는다. Canvas 폴백은 바닥 노멀 버퍼를 만들지 않는다.

압축 자산 전체 10MB·장면당 6MB 한도를 유지한다. CPU Canvas 검사, 브라우저 CPU 제출 시간, rAF 간격, WebGL GPU 타이머를 구분한다. 모바일 화면 모의는 실물 휴대전화의 성능·발열 검증이 아니다. 최종 수치는 [검증 기록](validation.md)을 따른다.

## 검토와 설치

작업은 기존 원본의 **재질 추가 작업**이며 전체 원화 재생성과 구분한다. [제작 경로](sprite-authoring.md)의 대표 검토 후 전체 검토를 따른다. 색 원본·노멀·명세·생성기·런타임·검토용 장면이 바뀌면 오래된 증거를 거절한다. WebGL 캡처에는 실제 backend와 노멀 draw 수를, 폴백에는 Canvas backend를 기록한다. 크기가 다른 PNG·누락 장면·미해결 관찰은 설치를 막는다. 합성 fixture로 검사한 gate 통과는 미감 검토가 아니다.

INT-19 전체 검토는 33개 화면이며 약한 불·강한 불·기본 광원의 노멀 없는 야간 장면을 포함한다. INT-20 `field-polish-v1`은 추가 프레임 페이지와 장면/UI 검토를 포함한 **43개**다. 진단광은 표면·번짐·그림자가 같은 배열을 사용하고 활성 그림자 raster도 이동해야 통과한다. 회귀 검사에는 벤치 다리 사이 alpha 여백·접촉, 랜턴 이동, 그림자의 지면 패스 순서, 품질 축소 시 공통 광원, 등각 지면 clipping, 테마별 alpha 마스크 캐시를 포함한다. 실제 GPU 픽셀로 주변광·거리 감쇠·노멀 없는 수광·발광/사진 예외·확대 불변을 확인한다. 같은 배열·서로 다른 raster만으로 자연스러움을 보장하지 않으므로 실제 PNG도 열어 비교한다.

검토 묶음은 버전별 `art/sprites/<material-id>/release/`에 보존한다. `material-release.json`이 현재 검토본을 가리키며 기본 `sprites:build`는 이를 재현한다. 이전 색 원본과 검토 묶음은 보존한다. 로컬 설치는 공개 배포가 아니다.
