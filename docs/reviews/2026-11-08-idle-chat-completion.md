# ChatGPT 직접 작업: 완료한 준비와 남은 실제 제작

## 이번 대화에서 수행한 것

최신 PR #7의 core03 구현을 확인하고 중복 변경 없이 이어갔다. 초기 head는 a5662aa였으며 이후 188da22에서 현행 애니메이션 스킬을 plan03 기준으로 정리하고 실제 승인 PNG에 대한 독립 측정을 기록했다. 옛 plan02가 현재 기본 경로로 다시 적용되는 문서 충돌을 제거했다.

현재 작업 공간에서 승인된 NW 원본 521850바이트를 직접 읽어 SHA256을 확인했다. GitHub의 core03 다각형과 erosion 규칙을 독립적으로 계산한 CORE SHA가 job과 같았다. 10개 읽기 전용 검사를 통과했고, 형상이 다른 기존 후보는 경계/변화량 예산으로 차단됐다. 원본이나 게임 자산을 수정하지 않았다.

새로운 f2 단독 PNG를 image_gen으로 생성하고 실제 바이트·크기·RGBA를 검사했다. 결과는 요구 1086×1448이 아닌 **1055×1491**, 410286바이트, SHA256 `601601b94ab6fa5c1cabba3d11a7f93ac378c48555d633a853a05f81e9676338`였다. 캔버스 불일치에서 중단했으며 이 원본을 접합·축소·재정렬하여 완료로 처리하지 않았다. [실제 검사 JSON](2026-11-08-idle-core03-f2-retry.json)에 기록했다.

## 실제 완료 범위

하네스 구조, 고정 기준 원본·마스크, 플랜/요청서, 원본·파생물 분리, 자동 검사와 실행 전 경계는 준비됐다. 최신 시작 head 및 188da22의 원격 CI 성공을 직접 확인했다. 이번 후속 변경은 스킬·측정·결과 문서이며 실행 코드를 변경하지 않았다.

**완료되지 않은 것:** 유효한 f2/f3/f4, 실제 합성·4→1 루프, 사용자 모션 선택, native 64×96, 게임 자산 적용. 새 실패 PNG는 대화에 원본으로 제공됐지만 GitHub 바이너리 업로드는 미완료다. 따라서 '배포만 하면 되는 상태'가 아니다.

## 하지 않은 것

main 병합, 게임 시작, 공개 배포, 운영 DB/설정 변경, 원본 강제 리사이즈·크롭·알파 이진화·양자화·반전, 누락 프레임의 f1 반복·테스트 이미지 대체, 사용자 모션 승인 생성은 하지 않았다. Codex로 작업을 떠넘기지 않았다.

이번 생성 경로에서 같은 캔버스의 국소 편집이 실제로 성립하지 않았으므로 똑같은 요청으로 f3/f4를 양산하지 않았다. 다음 유효한 제작 증거는 요청문 추가가 아니라 **원본과 동일 캔버스를 유지하는 실제 f2 PNG**여야 한다.
