## 검사 기준

PR #7의 실제 head `a5662aa9f16741011512b579548e7921716a692f`를 확인하고 기존 core03 구현과 완료 기록을 보존했다. 새 코드를 이미 완료한 것처럼 중복 보고하지 않는다. 이번 검사는 실제 대화에 마운트된 원본 PNG에 대한 독립적인 Python/Numpy 측정이며 전체 프로젝트 테스트 재실행이 아니다.

## 원본과 마스크

- f1: `곱슬머리_소년의_후면_픽셀_아트.png`, 521850 bytes, 1086×1448 RGBA.
- 실제 SHA256: `c1d4bde7cb49cdba5a5221c7d967eb475593780779122279b350d317e2e3b95a`, 승인값 일치.
- plan03 다각형을 픽셀 중심 규칙으로 평가하고 4-neighbour erosion 4회를 적용했다. 선택 CORE 43422픽셀, 경계 2950픽셀, 전체 envelope 46372픽셀.
- 실제 CORE SHA256 `278c2b87052885e70323c3cf6e2b403a993dec31ad5168b5fa85ab814e29a93d`가 GitHub job에 고정된 값과 일치했다.

## 실제 수행한 10개 확인

승인 f1 바이트·캔버스, 동결 마스크 해시, 머리/하체의 CORE 제외, f1 복제의 가짜 모션 거부, 잘못된 캔버스 거부, 합성의 CORE 밖 RGBA 보존, 경계 RGBA 보존, 부적합 기존 후보 거부, f1 파일 미변경, 검사 후보 파일 미변경을 확인했다. 10/10 PASS다. 검사 산출물은 측정 JSON이며 새 원화나 완성 모션이 아니다.

별도 기존 대화 PNG `포근한_올리브_후디_소년_픽셀_캐릭터.png`도 진단용으로만 비교했다. SHA256 `57222fcc1f429230268e906b5d9dde7d90676bb1b872cd5c4698f88cf2cd9e27`, 537957 bytes, 1086×1448다. 이것은 새로 생성한 f2가 아니고 이전 실패 기록의 `a63ce88f…` 파일과도 다르다. f2로 등록하지 않았다.

이 후보의 CORE 내부 변경은 43412/43422픽셀, 합성 envelope 변경 비율 0.936168, premultiplied RGBA 평균 오차 18.423846, 경계 gradient 변화 최대 126.003922였다. 고정 예산 0.12/4/12를 넘으므로 차단했다. 합성 결과의 CORE 밖과 경계 픽셀 변화는 각각 0이다. 진단 합성은 메모리에서만 계산했으며 실제 합성 PNG를 저장하거나 승인하지 않았다.

## 원격 회귀 증거와 구분

최신 시작 head의 [GitHub CI](https://github.com/biru100/HuddlersFire/actions/runs/42454250492)를 직접 조회했다. verify job은 npm test, sprite pipeline, typecheck, lint, 격리 CI build, 업로드 없는 packaging 검사까지 success다. deploy job은 skipped다. 이것은 해당 head의 GitHub 실행 증거이며 이 로컬 검사에서 npm 전체를 재실행한 것은 아니다.

현재 컨테이너의 GitHub clone은 네트워크 이름 해석 실패로 수행되지 않았다. 프로젝트 전체를 받아 실행한 것처럼 주장하지 않는다. GitHub 연결 도구의 실제 코드·문서 조회와 위 독립적인 원본 측정을 사용했다.

## 후속 실제 제작 경계

모델 편집에는 승인 f1의 실제 PNG를 입력해야 한다. 생성 결과는 기대치가 아니라 실제 캔버스·SHA·디자인으로 판단한다. 규격이나 영역 품질이 실패하면 보존하고 중단하며 f3/f4로 확대하지 않는다. 모션 선택·native/runtime·게임 시작·배포는 완료 상태가 아니다.
