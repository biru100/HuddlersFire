## 공통 제작 요청

따뜻한 캠핑 게임의 Rounded 02 Rev2 캐릭터를 유지합니다. 밤갈색 곱슬머리, 세이지 후드티, 차콜 브라운 긴 바지, 갈색 신발, 둥근 신체 비율·편안한 정지 자세를 보존하세요. 같은 방향·같은 캐릭터의 **호흡 Idle 4컷**을 2×2 독립 셀로 제작하세요. 프레임 순서는 좌상 1 → 우상 2 → 좌하 3 → 우하 4 → 1입니다.

현재 v1 원본은 1254×1254, 셀 627×627입니다. v2도 가능하면 같은 격자와 여백을 사용하되, 생성 도구의 원래 해상도를 유지해 주세요. 도구가 다른 크기를 출력하면 그대로 전달하고 실제 격자·해상도를 명시하세요. 강제 리사이즈·재압축·색 양자화·반전·코드 재작화로 맞추지 마세요. 이번 요청은 64×96 네이티브 스프라이트 제작이 아닙니다.

1. **각 신발의 접지점을 따로 고정:** 발은 제자리에서 바닥을 지지하고 신발의 앞코·뒤꿈치·바닥 모양이 컷마다 늘어나거나 새로 그려진 듯 흔들리지 않도록 합니다. 쿼터뷰 두 발의 이미지 y가 다른 상태는 유지할 수 있습니다. 두 신발의 바닥을 한 수평선으로 강제하지 마세요.
2. **호흡의 변화 위치를 명확히:** 가슴/상체의 작은 팽창·이완, 어깨와 후드의 미세한 동반 움직임으로 읽히게 합니다. 전신 전체의 상하 이동과 무릎의 큰 굽힘이 호흡을 대신하지 않게 해 주세요. 1 중립 → 2 들숨 → 3 날숨 → 4 중립 복귀는 출발 가설이며, 더 자연스러운 미술 해석과 타이밍을 제안해도 됩니다.
3. **2→3을 우선 정리:** v1의 몸 중심은 2→3에서 NW 약 14.7px, SE 약 15.5px 이동합니다. 숫자만 줄이는 목적보다, 접지를 유지한 작은 호흡 단계로 연결되게 수정하세요. 4→1도 포함해 모든 전환을 같은 리듬으로 검토하세요.
4. **형태의 연속성:** 곱슬머리의 큰 덩어리 수·흐름·윤곽, 후드 테두리와 부피, 소매·주머니·바지 주름, 신발 형태·색면을 컷마다 추적합니다. 우연한 모핑과 새로 생기는 주름/하이라이트를 줄이세요.
5. **알파 확인:** 투명 배경과 경계를 확인하고, 내부에 alpha 253 같은 거의 불투명한 값이 넓게 분포한 이유를 검토해 주세요. Codex가 기존 PNG의 알파를 임계값 처리해 수정하지 않습니다. 수정 결과를 새 원본으로 받습니다.

## NW 방향 추가 요청

왼쪽 위를 바라보는 뒷사선, 눈이 보이지 않는 뒤통수·등·내려진 후드를 유지합니다. 머리·어깨·골반·신발의 회전을 같은 방향으로 고정하고 호흡 때문에 시점이 흔들리지 않게 해 주세요. v1 컷1 발밑 마커는 셀 좌표상 L 약 (297.9,585), R 약 (375.5,570)입니다. 이는 **윤곽 측정 가설**이므로 원본과 대조해 실제 접점으로 사용할지 판단하고, 승인된 고정점으로 단정하지 마세요.

## SE 방향 추가 요청

오른쪽 아래를 바라보는 앞사선과 기존의 친근한 눈·입·귀를 유지합니다. NW 디자인과 같은 곱슬·후드·신발 비율을 유지하고, 얼굴·앞머리·후드 끈·주머니가 숨쉬기 중 다른 디자인으로 변하지 않도록 해 주세요. v1 컷1 발밑 마커는 L 약 (287.8,595), R 약 (375.5,578)이며 역시 원본 검토가 필요한 측정 가설입니다.

## 미술 평가와 전달

- 새 후보가 호흡으로 읽히는지, 접지·헤어·의상·얼굴·전체 루프가 일관되는지 ChatGPT가 실제 이미지를 평가해 주세요. Codex 측정 결과를 미술 PASS로 대신하지 마세요.
- 사용자에게 NW/SE 각 새 시안을 개별 선택받습니다. 기존 디자인 승인을 모션 승인으로 자동 적용하지 않습니다.
- 신규 PNG는 `rounded02-idle-motion-02`처럼 **새 불변 경로·새 MANIFEST·SHA256SUMS**로 GitHub에 저장합니다. 기존 원본/해시/리뷰를 덮어쓰지 않습니다. 실제 GitHub 바이너리 업로드가 불가능한 환경이면 생성 원본 PNG를 직접 Codex에 첨부합니다. ZIP은 필요 없습니다.
- 원격 바이트 해시 검증과 별도 motion-lookdev 수신·기술 검토를 진행합니다. 이번 단계에서 네이티브 변환·게임 교체·배포는 하지 않습니다.
