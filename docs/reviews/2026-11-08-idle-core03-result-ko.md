## f2 생성에서 실제로 막힌 지점

- 요구 원본 캔버스: **1086×1448**.
- 생성 도구의 실제 출력: **1055×1491 RGBA PNG**, 474,317바이트.
- SHA256: `a63ce88ff8d5277816daa15a66f4e446fde009dfb4bed1077cee3118b9a7f923`.
- 실제 `idle-frames.mjs intake` 결과: **exit 1**, `Canvas mismatch; never resize received art`.
- 원본 파일은 그대로 보존했다. 강제 축소·크롭·알파 변환·양자화로 통과시키지 않았다.
- 시각 검토에서도 기존 기준의 곱슬머리·후드·팔·바지·신발 형태와 배치가 달라, 목표한 국소 들숨 프레임으로 선정하지 않았다.

[실제 실패 보고 JSON](2026-11-08-idle-core03-f2-pilot.json). 생성 PNG는 이 ChatGPT 대화에서 원본으로 제공됐다. **해당 신규 실패 PNG의 GitHub 바이너리 업로드는 아직 완료하지 않았으며**, 이 보고서나 해시만으로 원본 업로드 완료라고 표시하지 않는다.

`f2/f3/f4`의 유효한 원본과 실제 합성·루프는 아직 없다. 실패한 f2를 기준으로 나머지를 양산하거나, 과거 시트·테스트 픽셀을 새 원화로 사용하지 않았다. 모션 미술 승인, 네이티브 64×96, 게임 적용과 배포는 계속 별도 미완료 상태다.

## 다음 제작의 기준

다음 시도는 새 4컷 시트를 다시 만드는 것이 아니라, **정확한 f1 원본을 실제 편집 입력으로 사용하여 동일 캔버스의 국소 상체 변화 한 장을 확보하는 것**이다. 이번 생성 경로가 그 요구를 충족했다고 주장하지 않는다. 적합한 f2가 확보된 후에만 f3/f4와 실제 루프 검토로 진행한다. 현재 하네스는 그 차이를 숨기지 않고 차단하는 상태로 준비돼 있다.
