# 불멍 놀이터의 제품 방향

**최신 공개 방향은 INT-18의 게임 필드 전면 재구성이다.** 모임·놀이·전시 의도를 유지하며 세 맵의 배치·모든 필드 그림·카메라·필드 HUD를 새로 만든다. 재킷 캐릭터, 불을 향하는 16석, 목적지로 이어지는 길, 같은 관람선의 게임 전시대를 기준으로 [설계](field-v2-design.md)를 따른다. 아래 공개 버전 28은 이전 INT-17 배포 기록이다. 초기 구현 승인 이후 사용자가 배포·커밋·푸시를 요청해 공개 버전 29·규약 v19로 반영했다.

INT-17 후속 배포 결과: 사용자 “배포해줘” 요청으로 **공개 버전 28·규약 v18**에 반영했다. 아래 로컬/미배포 표기는 초기 구현 승인의 경계이며 이번 후속 승인으로 대체한다.

2026-11-05 일러스트 전면 재구성 승인(INT-17)까지 반영한 제품 방향. 결정의 근거·범위·보류·충돌 처리는 [의도 기준](project-intent.md)을 따른다. 현재 구현의 설명은 [구조 문서](architecture.md), 검증 근거는 [검증 기록](validation.md), 의도와 구현의 차이는 [제품 검토](product-review.md)에서 관리한다. [초기 계획](plan.md)은 변경 전 결정의 기록이다.

## 사용자가 확정한 목적

최신 표현은 **INT-17의 따뜻한 구아슈 일러스트 캠프**다. 사진 머리를 가진 작은 캐릭터와 그려진 숲·모닥불·놀이터·전시 부스가 같은 시각 언어를 사용한다. 로비의 큰 미리보기와 준비/만나기 카드가 입장을 안내하고, 필드와 대화 패널을 구분해 머무르기와 조작을 이어 준다. 컬러/다크 선택과 색 이외의 표식은 유지한다. 이 소스는 로컬 구현·검증본이며 아래 공개 버전 기록을 새 배포로 해석하지 않는다.

최신 표현 기준은 **INT-16의 컬러·다크 모드 선택**이다. 기본 컬러 모드에서 크림색 UI, 초록 지형과 따뜻한 불꽃·캐릭터 색을 사용하고, 설정에서 기존 흑백 다크 모드로 바꿀 수 있다. 개인 브라우저에 저장하며 로비·방 화면·필드와 음악 작은 창에 함께 적용된다. 테마 선택은 다른 사람의 화면이나 방의 공용 불 외형 선택에 영향을 주지 않는다. 외부 콘텐츠의 원색과 색 이외의 구분 표식은 유지한다. 후속 “배포해줘” 요청으로 공개 버전 27·규약 v17에 반영했다. 아래 INT-14·15의 흑백 설명은 이전 구현 이력이다.

INT-15 승인 당시에는 기존 시각 계층을 제거하고 공식 SEED 기반 화면과 게임 필드를 새로 구성한다. 소개·프로필 준비·공간 선택을 나눈 로비, 필드 중심의 대화/사람/상태/놀이/라디오 패널, 통일된 팝업과 새 기하형 장면으로 이어진다. UI와 게임 필드의 블랙앤화이트, 외부 콘텐츠 원색, 기존 기능은 유지한다. 후속 배포 요청으로 재구축을 공개 버전 26·규약 v17에 반영했으며 아래 공개 버전 25는 이전 부분 전환 이력이다.

INT-14의 SEED·흑백 재구성은 후속 “배포해줘” 요청에 따라 공개 버전 **25**에 반영했다. 아래 초기 구현 범위의 “공개 배포는 별도”는 당시 승인 경계이며, 이번 후속 요청으로 해당 변경의 배포까지 승인됐다.

2026-11-05 INT-14에 따라 UI와 게임 필드를 SEED Design과 블랙앤화이트 톤으로 재구성한다. 함께 쉬고 놀며 개발·게임을 이야기하는 목적은 이어간다. 외부 프로필 사진·게임 이미지·영상은 원색을 유지하고, 직접 그리는 지형·캐릭터·불꽃과 앱 조작 UI에는 무채색을 사용한다. 색으로만 구분하던 목적지·캐릭터·불 외형은 표식·명도·형태로 구분한다. 이 흑백 고정 기준은 이후 INT-16의 두 모드 선택으로 대체됐다.

> 인디게임개발자 디스코드 커뮤니티에서 사람들이 함께 온라인에서 온기를 느끼고 놀 수 있는 하나의 불멍 놀이터를 만든다.

2026-11-04 의도 인터뷰에서 사용자는 다음 장면을 **모두 보고 싶다**고 답했다. 이 답변이 기능별 개발 순서나 같은 비중의 화면 배치를 확정한 것은 아니다.

| 원하는 장면 | 경험을 검토할 때 볼 것 | 현재 이를 돕는 구현 |
| --- | --- | --- |
| 말없이 곁에 앉아 쉬기 | 대화나 조작을 계속하지 않아도 함께 있는 느낌이 드는가 | 앉기, 캐릭터와 이름, 모닥불, 개인별 소리 설정 |
| 이야기하며 장난치기 | 움직임과 반응이 귀엽고 서로 놀이를 이어 갈 수 있는가 | 채팅·말풍선, 감정표현, 달리기·점프, 연쇄 들기, 장난감, 트램펄린 |
| 각자 개발하다 잠깐 만나기 | 각자 작업하면서도 상호작용하고 돌아왔을 때 친구를 알아볼 수 있는가 | 같은 방에 머물기, 작업 메모·수동 상태·호출, 필드 보기·줌·PIP, 공용 라디오 자동 재생과 개인 음소거 |
| 만든 게임을 보여 주고 이야기하기 | 소개와 반응이 자연스럽게 오가는가 | 포탈로 가는 별도 게임 전시장, 가까운 부스에서 소개 팝업·공식 링크, 일반 채팅. 화면 공유·피드백 보관은 없음 |

위의 검토 기준은 목적을 관찰 가능한 질문으로 풀어 쓴 것이다. 실제 커뮤니티 사용을 통해 기준을 보완한다. 전용 기능을 모두 만들어야 한다는 요구로 해석하지 않는다.

## 휴식과 놀이의 관계

사용자는 불멍에서 밀치기와 놀이가 섞여 산만한 문제를 해결하기 위해 **같은 방 안의 별도 놀이터 맵**을 요청하고 구현 계획을 승인했다(INT-08).

- 처음에는 불멍에 입장하고 △ 포탈로 놀이터, □ 포탈로 허들러즈 게임 전시장에 간다. 가까이에서 E 또는 상호작용 버튼을 누르며 돌아올 때는 ○ 포탈을 이용한다. 선 패턴과 목적지 이름도 함께 표시한다. 맵마다 사람과 배치가 따로 보이며 참가자 목록은 현재 장소를 표시한다.
- 각 맵은 가로·세로 약 2배, 면적 약 4배로 넓어졌다. 기본은 내 캐릭터 따라가기이며 전체 보기와 휠 확대·축소도 제공한다. 전시장 부스 가까이에서 E 또는 소개 보기 버튼을 누르면 게임 소개·이미지·관련 링크가 열린다. 첫 전시는 clukostudio.com의 PARRUITS!이며 링크는 새 탭에서 연다.
- 후속 부스 템플릿(INT-13)은 필드 대표 이미지와 트레일러 중심 소개·SNS 아이콘을 같은 게임 정보로 구성한다. 영상은 사용자가 재생하고 닫으면 제거하며 공용 라디오 상태는 유지한다. SNS 링크가 미등록이면 해당 아이콘은 비활성 상태로 보인다. 추가 게임 작성법은 [부스 템플릿](game-exhibits.md)에 둔다. 사용자 후속 배포 요청으로 공개 버전 22에 반영했다.
- Torizon Telecom 추가 승인에 따라 같은 템플릿의 두 번째 부스를 구성했다. 공식 YouTube 썸네일·트레일러와 소개, Steam 위시리스트·데모, 등록된 SNS를 제공하며 Instagram·TikTok은 미등록으로 비활성화한다. 후속 “배포해줘” 요청으로 공개 버전 24에 반영했다.
- 불멍에는 모닥불과 라디오를 두고 걷기·달리기·점프·앉기·감정표현을 유지한다. 총·눈뭉치·폭탄·들기·던지기는 놀이터에서만 가능하다. 축구공·트램펄린도 놀이터에 둔다.
- 놀이의 투사체·폭발·밀림·들기와 선택 판정은 다른 맵에 영향을 주지 않는다. 이동 시 본인만 옮기며 들기 연쇄의 나머지는 원래 맵에 안전하게 내려놓는다. 낙사하면 현재 맵으로 돌아온다.
- 방 코드·전체 채팅·라디오 자동 재생·개인 음소거·작업 시간은 맵 이동과 별개로 이어진다. 신청곡·공용 재생과 개인 소리는 어디서든 라디오 탭 또는 R로 관리한다. 현재 곡이 없으면 누구의 신청이든 바로 재생하고 다음 곡은 순서대로 이어진다. 전체 일시정지·재개·다음 곡·대기곡 삭제는 방장 권한이며 새 신청으로 수동 일시정지를 풀지 않는다.
- 작업 중·자리 비움은 여전히 상호작용의 면책 조건이 아니다(INT-02). 놀이터에서는 기존 동의·앉기·탈출·공중 잡기 규칙을 따른다.

## 통나무에서 쉬기

불멍에는 불 둘레의 통나무 8개·16개 좌석과 통로가 있다. 통나무 양쪽과 끝에 가까이 가서 클릭·터치·E로 앉으면 불 중심으로 확대하고 일어나면 평소 화면으로 돌아온다. 바닥에 앉아 있어도 가까운 빈자리로 옮겨 앉을 수 있다. 통나무에서는 최근 불멍 대화를 불 위에서 읽고 장작을 넣을 수 있다. 불은 캠프 시각에 따라 줄어들지만 작은 잔불은 남는다. 장작은 **인당 10분에 한 번** 넣으며 남은 시간이 표시된다. 불 크기에는 상한이 있고 성공한 장작 투입만 방의 공동 경험치가 된다.

현재 수치는 장작 1회 +1 XP, 3 XP마다 레벨업이며 최고 5레벨이다. 레벨마다 은빛 잔불→하얀 꽃불→물결불→오로라불→별불을 해금하며 꽃잎·물결·세로 빛줄기·별 형태로 구분한다. 불멍에 있는 참가자 누구나 해금된 모습 중 하나를 선택하면 방 전체에 같은 모습이 적용된다. 레벨업이 기존 외형 선택을 자동으로 바꾸지는 않는다. 연료 감소와 성장은 별개이므로 잔불이어도 경험치·해금은 유지한다. 좌석·불·장작 대기시간·공동 성장과 외형은 방장 승계에서도 이어지고 방이 끝나면 초기화한다. XP·상한·외형은 현재 구현 세부로 조정할 수 있다.

선택한 사람의 캐릭터와 말풍선은 통나무에 앉아 있는 동안 내 필드에서만 숨길 수 있다. 사람 목록에서 다시 표시할 수 있고 전체 채팅은 유지한다. 방 퇴장 시 선택을 비우며 운영 차단 기능으로 취급하지 않는다. 대화·작업·자리 비움은 수동 상태로 머리 위에 표시한다. 라디오 탭에서는 신청곡·음악과 개인 라디오/모닥불 음량을 관리한다.

## 현재 제품의 경계

- 웹에서 공개방 목록·초대 링크·코드로 최대 16명이 만나는 일시적인 캠프장이다. Discord 계정을 연결해야 입장할 수 있다. 새 방은 공개방과 목록에 없는 초대방을 선택하며 기존 방은 자동 공개하지 않는다. 공개방은 Discord 계정을 연결한 사람이 입장할 수 있으며 특정 서버 소속은 검사하지 않는다.
- 게임 상태 전송과 판정은 P2P를 유지한다. 네트워크 개선 논의에서 사용자가 서버 중심 전환에 이의를 제기했고, P2P 전송 최적화의 구현·검증·배포를 승인했다. 로비·인증·접속 협상의 서버 역할과 게임 데이터 중계를 구분한다.
- Discord는 입장 자격과 프로필 사진 연결에 사용한다. 커뮤니티 소속 검사, 자동 음성방 입장, Discord Activity는 구현하지 않았다. 음성 대화는 기존 Discord 통화를 사용한다.
- 방장 이탈 시 같은 코드 안에서 후임에게 승계한다. 전원이 떠난 뒤에도 유지되는 공용 광장이나 영구 저장소는 아니다.
- 라디오가 재생되면 같은 방의 모두가 자동으로 듣고, 음소거·음량은 개인별로 선택한다. 라디오 접근·팝업 열기는 듣기 조건이 아니며 신청곡·방장 전체 재생 조작에 사용한다. 들리기 허용도 개인별 선택이다. 작업 중·자리 비움은 상호작용을 막지 않는다. 상태 변경은 앉기·공중 동작·들기 연쇄를 강제 변경하지 않는다. 앉은 상대는 들 수 없고 앉아서 다른 사람을 들 수도 없다. 개인 피격 거부 설정은 없으며 놀이 가능 여부는 현재 맵으로 결정한다(INT-08).
- YouTube 영상은 표시를 유지한다. 모바일 필드에서는 창의 여백을 줄이고 긴 안내문·미지원 작은 창 버튼을 숨겨 차지하는 면적을 줄인다. 곡 제목·개인 음소거와 200×200px 이상 영상은 유지하며 데스크톱 창은 기존 배치를 따른다.
- 대화를 기본 패널로 두고 사람·내 상태·놀이를 전환한다. 작은 화면과 필드 보기에서는 하단 메뉴로 패널을 열고 닫는다. 초대 정보는 펼쳐 보고, 긴 메모는 참가자 상세에서 읽는다.
- 이름표는 나무·텐트·통나무 등 지형 위에 표시하며 보이는 이름표를 눌러 해당 참가자를 선택한다. 확대·축소는 필드 위 마우스 휠로 조작하고 왼쪽 상단의 확대/축소 버튼·배율 표시는 제거한다. 위로 확대·아래로 축소하며 범위는 현재 75~300%다. 내 캐릭터 따라가기·전체 보기와 통나무 집중 보기·PIP는 유지하고 패널 위 휠은 패널을 스크롤한다.

## 방향을 갱신하는 방법

기능 완료나 제품 검토 요청을 계기로 관련 구현과 실제 흐름을 이 문서의 장면에 대조한다. 첫 검토는 전체 구조를 훑고, 이후에는 변경 부분과 영향 범위를 중심으로 확인한다. 방향 전환이나 공통 상태·입퇴장 변경은 검토 범위를 넓힌다.

관찰한 사실, 사용자가 확정한 의도, AI의 제안과 미정 사항을 구분한다. 질문은 다음 결정에 필요한 만큼만 하고, 답변을 받은 항목만 확정 기준에 반영한다. 이미 승인된 내용을 다시 승인받거나 매 작업마다 질문 횟수를 채우지 않는다. 빌드·테스트 통과와 ‘함께 있는 온기’를 확인한 실제 사용 결과는 별도로 기록한다.

## 공개방과 작업 동석 계획 승인 (2026-11-04)

아래는 당시 승인 기록이다. 이 중 AFK 보호 선택은 후속 INT-02 결정으로 대체되어 현재 제공하지 않는다.

피드백 검토 후 사용자가 공개방 목록을 추가한 단계별 계획의 구현·검증을 승인했다. 작업 상태는 수동으로 정하고 입력 부재를 자동 AFK로 해석하지 않는다. AFK 보호·장난 허용과 호출 수신을 선택하고, 채팅·호출의 날짜와 시각을 표시한다. 작은 화면은 웹 필드 보기와 지원 환경의 Document PIP부터 제공한다. 데스크톱 독립 앱, 수동 방장 지정, 영구 기록·종료 후 푸시 알림은 이번 구현 범위에 포함하지 않는다. 음성은 [기술 검토](voice-options.md)까지 진행했고 실제 도입 방식은 확정하지 않았다. 구현·로컬 검증과 공개 사이트 배포는 별도 상태다.

## 축구공·작업 시간·백그라운드 계획 승인 (2026-11-04)

사용자가 축구공 접촉 놀이, 채팅의 오래된 순서부터 아래로 쌓기, 본인의 작업 시간, 수동 상태 표시 보강과 백그라운드 문제 개선 계획을 승인했다. 작업 시간은 이번 입장의 ‘작업 중’ 상태 구간을 개인에게 누적 표시하고 다른 창에서 개발하는 시간도 포함한다. 대화 가능·자리 비움에서는 멈추며 영구 작업 통계는 포함하지 않는다. 공은 걷기와 달리기로 차는 놀이이며 골대·점수·팀전은 이번 범위 밖이다.

소리 방식은 당시 사용자가 **YouTube 작은 창**을 선택했다. 후속 2026-11-05 요청으로 작은 창 없이도 백그라운드에서 재생을 이어가도록 앱의 가시성 기반 일시정지를 제거했다. 공식 플레이어의 Document PIP는 선택 사항으로 유지하고 필드 PIP와 번갈아 사용한다. 주 창 종료·브라우저 동결·기기 절전 중 지속 실행은 보장하지 않는다. 휴식·놀이 구역은 이번에도 구현하지 않았으며 공간 분리 원칙과 세부 미정 사항은 유지한다. 공개 배포는 이번 구현·검증 승인에 포함하지 않는다.

## 전체 피드백 이후 변경 승인 (2026-11-04)

사용자는 작업 중에도 상호작용하기를 원하며 최종적으로 **보호 기능 제거 후 진행**을 선택했다. 이에 따라 기존 자리 비움 보호를 제거하고, 사람·상태·채팅의 접근성과 필드 상태 표식의 가독성을 개선한다. 관리 기능과 게임 소개 확장은 보류한다. 의도 문서·프로젝트 하네스·스킬을 함께 구성하되 AI의 주관과 자료가 사용자 목적을 대신하지 않도록 한다. 상세 범위와 변경 절차는 [의도 기준](project-intent.md)에 둔다.
