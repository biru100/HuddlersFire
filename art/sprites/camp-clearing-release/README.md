# Camp clearing terrain and seats

The warm timber bench and ground use the [scene-review inputs](../scene-reviews/camp-circle-se/README.md). The second orientation is the original transparent output of a ChatGPT built-in image edit using only the reviewed game bench. Its generated model identifier was unavailable. The request was:

> Game art edit, same exact backless two-person bench design and warm cozy chunky pixel art as the input sprite. Rotate this bench by a quarter turn ON THE GROUND of a 2:1 isometric game, so that its long axis now runs from the LOWER LEFT of the image to the UPPER RIGHT, roughly 2 pixels right for 1 pixel up, with the near end at left. Keep the broad three honey-larch planks, two dark umber trestles, a slimmer brace between, the rough knots and one mossy foot. Repaint lighting so the top and upper-left edges stay warm, and the near/exposed end shows endgrain and chamfer rather than copying a horizontal reflection. Camera remains elevated three-quarter; show the entire simple low bench, readable silhouette at 110 px final width, chunky clean pixel clusters and a tight warm palette, no people, no rocks/ground or cast shadow, one prop only. Center isolated on transparent background, drawn large with small margins. Bench seat depth, width and height should match input. Landscape canvas.

Run `node web/scripts/build-camp-clearing-art.mjs` after installing the web dependencies. The builder crops the two independent bench views, grades the weathered and monochrome variants, builds relief and blends the selected ground into moss, worn earth and ash. The game uses the real seat contact for each bench. The same artwork supplies its visible pixels and projected shadow.
